Four free families, all under the SIL Open Font License. Each one has a single job. Part of [[Ardentia]].

## Note text

Designed by the Braille Institute to tell apart the letters that tend to blur together. In a long note, that means less effort to decipher and more attention on what is written, with real **bold** and *italic*.

Hard pairs: Il1 O0 rn m B8 ce qg

## Code

```ts
// comments and keywords in cursive italic
const ignite = (sea: Wave[]) =>
  sea.filter((w) => w.energy !== 0);
```
