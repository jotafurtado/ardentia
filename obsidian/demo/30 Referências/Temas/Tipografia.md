Quatro famílias livres, todas sob a licença SIL Open Font. Cada uma tem um trabalho só. Parte de [[Ardentia]].

## Texto da nota

Desenhada pelo Braille Institute para separar as letras que costumam se confundir. Em nota longa, isso vira menos esforço para decifrar e mais atenção no que está escrito, com **negrito** e *itálico* de verdade.

Pares difíceis: Il1 O0 rn m B8 ce qg

## Código

```ts
// comentário e palavra-chave em itálico cursivo
const acender = (mar: Onda[]) =>
  mar.filter((o) => o.energia !== 0);
```

Ligaduras: `=> !== >= -> :: </>`

Algarismos: 0123456789
