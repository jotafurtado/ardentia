# Changelog

## 1.0.0

First version of the Ardentia port for VS Code.

- Workbench colors for the editor, side bar, panel, terminal, status bar, menus, notifications and the other surfaces listed in the README.
- TextMate token rules for the common languages and for Markdown, with one color per heading level.
- Semantic highlighting enabled, with rules for the standard token types.
- The 16 terminal colors shared with the Zed, Ghostty and Herdr app ports.
